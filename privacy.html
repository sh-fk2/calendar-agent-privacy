日本語

1. このアプリについて

tech-event-calendar-agent は、開発者個人が自分の Google アカウントだけを対象に運用する自動化ツールです。 他の利用者はいません。

2. アクセスする Google ユーザーデータと目的

  • Gmail（gmail.readonly）: 勉強会・カンファレンスの申し込み完了メールを検索し、本文を読み取ります。目的は、イベント名・日時・場所・URL を取り出すことだけです。メールの削除・送信・変更は行いません。
  • Google カレンダー（calendar.events）: 取り出したイベントを、同じアカウントのカレンダーに登録します。

3. 取り扱いと保存

  • メール本文の先頭 6,000 文字までと送信元ドメインは、イベント情報の抽出のために Amazon Web Services（Amazon Bedrock）へ送信されます。抽出以外の目的には使いません。
  • 保存するのは、処理済みメールの ID、抽出したイベント情報（名称・日時・場所）、処理の結果、Google の更新トークンです。メール本文そのものは保存しません。処理の記録は 180 日で自動的に削除されます。
  • 登録するイベントには、開発者本人が設定したメールアドレスを参加者として加え、カレンダーの招待メールを送ることがあります。
  • 更新トークンは AWS Secrets Manager に暗号化して保管します。
  • データを第三者へ提供・販売することはありません。広告にも使いません。人が読むこともありません（開発者本人が自分のデータを確認する場合を除く）。

4. Google API サービスのユーザーデータに関するポリシーについて

このアプリによる Google API から受け取った情報の利用と他のアプリへの転送は、 Google API サービスのユーザーデータに関するポリシー （Limited Use の要件を含む）に準拠します。

5. データの削除とアクセスの取り消し

Google アカウントの権限設定から、いつでもこのアプリのアクセスを取り消せます。 保存したデータの削除は、下記の連絡先へご連絡ください。

English

1. About this app

tech-event-calendar-agent is a personal automation tool operated by its developer against the developer's own Google account only. There are no other users.

2. Google user data accessed and why

  • Gmail (gmail.readonly): searches for event-registration confirmation emails and reads their text, solely to extract the event name, date and time, location, and URL. It never deletes, sends, or modifies email.
  • Google Calendar (calendar.events): adds the extracted events to the same account's calendar.

3. Handling and storage

  • Up to the first 6,000 characters of an email's text, plus the sender's domain, are sent to Amazon Web Services (Amazon Bedrock) to extract the event details. They are not used for any other purpose.
  • What is stored: IDs of processed emails, the extracted event details (title, date and time, location), the processing result, and the Google refresh token. The email text itself is not stored. Processing records are deleted automatically after 180 days.
  • An email address configured by the developer may be added as an attendee to the registered events, in which case Google Calendar sends it an invitation email.
  • The refresh token is kept encrypted in AWS Secrets Manager.
  • The data is never sold or shared with third parties, never used for advertising, and never read by humans (other than the developer reviewing their own data).

4. Google API Services User Data Policy

The use and transfer to any other app of information received from Google APIs by this app adheres to the Google API Services User Data Policy, including the Limited Use requirements.
